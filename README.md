让 Coo 坐在屏幕边陪你**学英语**：读英文原文 → 点词看释义与词根 → 点句让 Coo 翻译讲解 →
进生词本 → 按间隔复习。

## 学习版说明

- 评论态度**锁定「严谨」**，只做语言与剧情的中性说明；
- 「开发者模式」及其他模式**置灰、不可点**，部分选项加删除线；
- 本版本只保留英语学习所需的查词、词根、整句讲解、生词复习与朗读；
- 不提供与学习无关的内容档位。

## 具体功能

- **点词卡**：音标、词性、中文释义、词根拆解、同根词；本地词典与 Coo 的补充并存显示。
- **问 Coo 这个词**：本地词典已收录时，也能让 Coo 补充语境、搭配与易混点。
- **整句讲解**：Alt+点击句子或选中一段英文，Coo 回传中文翻译与 1–3 条讲解。
- **生词本**：加入、编辑、导入 JSON/CSV、按 1/2/4/7/15/30 天复习。
- **朗读**：单词卡支持系统语音合成，可调语速。
- **非学习模式**：只想玩时可关闭查词、翻译、生词与复习，只保留 Coo 的陪玩评论。

## 使用方法

1. 安装本 World（Coopanion → 扩展 → 从本机目录安装），**重启 Coopanion** 并启用；
2. 安装 DoL 模组 `CooBridge.mod.zip`（游戏 Mod 管理器 → 添加旁加载 Mod → 重新载入）；
3. 打开游戏，右下角出现 Coo 圆点；绿色表示已连接；
4. 点单词、Alt+点击句子，或在 Coo 面板里查看当前学习状态；
5. 首次连接时回答 Coo 的「学英语 / 只想玩」，之后可在面板随时切换。

完整安装与排查：https://github.com/Funst-666606/coo-reads-dol

## 实验性说明

- 目前只验证 **Degrees of Lewdity 0.5.12.13 + ModLoader 2.101.1**（Windows）；
- 属于**高消耗**扩展：每个场景、翻译与评论都会调用模型；
- 需要**额外安装**游戏本体、ModLoader 与配套的 DoL 模组；
- 本学习版不提供与学习无关的模式，评论保持严谨、中性；
- 汉化环境会自动切换为非学习模式，不再停用模组。

## AI 声明

运行时的评论与翻译由 Coo 的 LLM 生成；按交互文本估算约占 60%，其余 40% 为本地词库、
词根、UI 与固定文案。代码为 AI 辅助编写。
