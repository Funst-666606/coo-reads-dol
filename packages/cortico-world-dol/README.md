# 欲都孤鱼与多邻鱼 · 学习版

Cortico World 扩展：把 **Degrees of Lewdity 英文原版**的场景交给 Coo，并把玩家点选的句子/单词
转给 Coo 讲解，再把答复送回游戏，用于英语学习。

## 学习版

- 评论态度锁定「严谨」，只做语言与剧情的中性说明；
- 「开发者模式」与其他模式置灰、不可点；
- 只保留查词、词根、整句讲解、生词复习与朗读。

## 安装

1. 解压到固定目录；
2. Coopanion → 扩展 → 从本机目录安装；
3. 重启 Coopanion 并启用；
4. 游戏内安装配套 `CooBridge.mod.zip`。
