# 变更日志

## 0.1.5 - 2026-11-01

- 「每日评论上限」默认改为 0（不限）；仍可在配置里设上限。

## 0.1.4 - 2026-11-01

- 环境提示词：玩家对已有本地释义的词也可能来问，要求给语境补充、不无理由否定本地释义。

## 0.1.3 - 2026-11-01

- 修：断线重连抖动时，30 秒内只推一次连接状态，避免 Coo 被「已连接 / 断开」刷屏。

## 0.1.2 - 2026-11-01

- 新增 `dol_vocab_edit` 工具：Coo 可以在玩家明确要求时加入 / 删除 / 标记掌握本地生词。
- 面板：三种陪读模式的说明与当前模式；生词表增加「掌握」列。
- 生词镜像记录「掌握」状态，到期的统计与列表排除已掌握的词。

## 0.1.1 - 2026-10-31

- 修：汉化检测按「正文语言」判定，`I18nTweeReplacer` 这类通用插件不再误判为汉化。
- 停用提示改为顶部可关闭横幅，不再全屏遮挡 Mod 管理器。
- 配置组路径补上 `worlds.dol.` 前缀（此前设置写错段）。
- 新增 `dol_vocab` 工具（生词统计 / 最近加入 / 今天到期）。
- 协议与 mod 侧支持端口覆盖（`window.CooBridgePort` 或 localStorage `cb.port`）。

## 0.1.0 - 2026-10-31

首个可用版本（本地跑通，未发布）。

- 本地 WebSocket 服务（默认 `127.0.0.1:17321`，被占顺延），只接受 `file://` 与本机来源。
- 协议 v1：`hello` / `scene` / `choice` / `sentence` / `word` / `vocab`，请求按 id 对应，20 秒超时。
- 工具：`dol_teach`（回传翻译与讲解）、`dol_define`（补全未收录词）、`dol_now`、`dol_mode`、`dol_vocab`。
- 事件：连接/断开、场景、选择、学句请求、查词请求、生词变动。
- 三档模式：主动 / 触发 / 被动；每日评论上限。
- 生词镜像：落盘 `dol-vocab.json`，面板可看、可导出 CSV/JSON。
- WebUI 面板：连接状态、端口、当前场景、今日评论、生词表、模式切换、导出。
- 配置组 `worlds.dol.*`：端口、模式、每日上限、场景文本上限、讲解超时。
- 环境提示词：告诉 Coo 怎么读事件、怎么回传、不剧透、成人内容中性讲解。
