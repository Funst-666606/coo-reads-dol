# 变更日志（模组）

## 0.1.8 - 2026-11-01

- 词库界面标出 Coo 新增/改动的词（Coo 标签 + 顶部计数）。
- 新增「只看 Coo 改动」筛选，方便查看与修改 Coo 动过的词。

## 0.1.7 - 2026-11-01

- 设置页新增「端口」：可改 World 连接端口，保存后重新载入游戏生效。
- 生词本页面新增词库管理：查看、手动添加、编辑释义、删除、导入 JSON / CSV。

## 0.1.6 - 2026-11-01

- 单词卡永远显示「问 Coo 这个词」，本地词典收录的词也能问。
- 本地词典与 Coo 的释义 / 音标 / 词根**并存显示**（分「本地词典」「Coo 补充」两块），不再互相替代。
- 生词本支持用 Coo 的释义更新已有词条；Coo 的 `dol_vocab_edit add` 对已有词会覆盖释义。

## 0.1.5 - 2026-11-01

- 修：点击事件改为全局委托，不再要求落在正文容器内。侧栏、二级面板（MapleBirch 的
  `#passage-content` 之外）现在也能点词、Alt+点句、选中问句。
- 修：按钮、链接、输入框等交互元素不再误触发查词。

## 0.1.4 - 2026-11-01

- 修：模组每 60 秒被 World 判定静默并断开，随后重连又不发场景，形成「断线重连循环」并把 Coo 刷屏。
  现在每 20 秒发一次心跳；重连后会重发当前场景。
- 修：连接被另一个游戏页面接管（close 4001）时不再立即重连，改为 30 秒后重试，避免两个页面互相顶掉。

## 0.1.3 - 2026-11-01

- 新增：模组设置菜单（点词查义、Alt+点击问句、朗读开关、朗读语速），设置存本地。
- 新增：接受 Coo 的 `vocab` 命令，可加入 / 删除 / 标记掌握本地生词本。
- 朗读按设置里的语速播放。

## 0.1.2 - 2026-11-01

- 新增：单词卡上的 🔊 朗读。使用系统语音合成，离线；优先选本地英文嗓音，语速略慢。
- 不支持语音合成的环境会提示一次，不会报错。

## 0.1.1 - 2026-10-31

- 修：汉化检测改为按正文语言判定，`I18nTweeReplacer` 等通用插件不再误判。
- 停用提示改为顶部可关闭横幅，不再遮挡 Mod 管理器。
- 支持端口覆盖（`window.CooBridgePort` / localStorage `cb.port`）。
