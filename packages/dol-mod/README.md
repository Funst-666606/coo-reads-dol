# 欲都孤鱼与多邻鱼 · CooBridge

让 Coo 陪你玩 Degrees of Lewdity：可以学英语（点词、词根、整句讲解、生词复习），
也可以只陪玩（非学习模式）。

- 作者：Funst-666606（QQ：烦伪2674459204）
- 许可证：CC BY-NC-SA 4.0
- 适配：Degrees of Lewdity 0.5.12.13（ModLoader 2.101.1 构建）
- 18+：模组本身不新增成人文本，但运行在成人游戏中，且「色情 / 淫乱」评论档位为成人内容，默认关闭。

## 安装

1. 使用带 ModLoader 的英文原版 DoL；
2. Mod 管理器（Alt+M）→ 添加旁加载 Mod → 选 `CooBridge.mod.zip` → 重新载入；
3. 右下角出现 Coo 圆点，绿色表示已连接到 Coopanion 的 World。

## 说明

- 汉化环境不会停用模组，会自动切换为非学习模式；
- 生词、设置存在游戏浏览器的 localStorage，清理站点数据会丢失，建议先导出；
- AI 声明：运行时的评论与翻译由 Coo 的 LLM 生成；按交互文本估算约占 60%，
  其余 40% 为本地词库、词根、UI 与固定文案。代码为 AI 辅助编写。
