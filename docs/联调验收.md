# 联调与验收清单

> 目标：用最短路径确认「装得上、连得上、点得动、存得住」。
> 任一步失败，把该步的**现象 + 自检文本 + 控制台日志**发我。

## 0. 准备

- [ ] Coopanion 0.2.16 已安装并运行（按你的实际安装路径）
- [ ] 英文原版游戏（**不装** ModI18N 汉化包）
- [ ] 本仓库已构建：`node scripts/build-all.mjs`
- [ ] 可选、但建议：`node scripts/fw-check.mjs` 通过（用 Coopanion 自带的 manifest / dry-mount / describe 校验）

## 1. 安装 World

1. Coopanion → **World extensions** → 手动安装 → **从本机目录安装**
2. 选 `packages/cortico-world-dol`
3. 重启 Coopanion
4. World 总览 → 启用「DoL 陪读」

预期：
- [ ] 侧栏出现「DoL 陪读」页
- [ ] 页内有「陪读」面板：连接=未连接、端口=17321
- [ ] 面板不报错（若报错，记下红字）

失败排查：
- 装不上：看 Coopanion 的 `data/logs`，多半是 `cortico.api` 不符或 `ws` 没装上
- 页面白屏：`dist/webui.js` 是否随包安装（本仓库已构建过）

## 2. 安装模组

1. 打开游戏 → 左下角 **Mod 管理器**
2. 添加旁加载 Mod → 选 `packages/dol-mod/CooBridge.mod.zip`
3. 重新载入

预期：
- [ ] 右下角出现 `Coo` 圆点
- [ ] 圆点约 1–2 秒内变绿（World 未启用时为红/灰）
- [ ] 控制台有 `[CooBridge] 已加载 0.1.0，游戏 0.5.12.13`

## 3. 连接与场景

- [ ] 换 3 个场景，Coo 收到场景事件（World 面板「当前场景」跟着变）
- [ ] 面板「今日评论」计数增加（上限 40）

## 4. 查词

点 `incredible`：

- [ ] 卡片出现：单词、音标、`adj.`、中文释义
- [ ] 词根块显示 `in-（前缀·不…） + cred（词根·相信） + -ible（后缀·能……的）`
- [ ] 同根词：credit / credible / incredulous
- [ ] 点「加入生词本」→ 按钮变「已加入」

点本地没有的词（如 `shudder`）：

- [ ] 卡片显示「本地词典未收录」+「问 Coo 这个词」
- [ ] 点了之后出现「Coo 正在想…」，随后释义上卡，来源显示「AI 推测（Coo）」

点 `dog` / `table`：

- [ ] 词根块显示「无可靠词根」（不能硬编）

## 5. 问句

- [ ] **Alt + 点击**任意一句 → 「Coo 正在想…」
- [ ] 20 秒内出现中文翻译 + 1–3 条讲解
- [ ] 同一句再点一次：立即显示（缓存命中），无新请求
- [ ] 选中一段英文后松开：同样出卡

失败：
- 一直「正在想」：Coo 没接模型 / 正忙；看 World 面板连接状态与 Coo 是否在说话
- 20 秒后「没等到」：点重试；连续失败看 Coopanion 日志

## 6. 生词本与复习

- [ ] 加 3–5 个词，关游戏重开，生词仍在
- [ ] 圆点 → 面板 → 生词：列表可见、可删
- [ ] 复习页：到期词出现，点「认识」后消失、「不认识」后仍在
- [ ] 导出 CSV：Excel 打开不乱码，列不串
- [ ] World 面板的生词镜像数量与游戏内一致

## 7. 汉化拦截

装回 `ModI18N.mod.zip` 后启动：

- [ ] 出现「CooBridge 已停用」全屏提示
- [ ] 没有 `Coo` 圆点、没有 WS 连接
- [ ] 游戏本身能正常玩

## 8. 稳定性

- [ ] 连续玩 20 分钟：无报错弹窗、无卡顿、存档正常
- [ ] 关掉 Coopanion：游戏不卡，圆点变红；重开 Coopanion 后 30 秒内自动变绿

## 自检怎么取

游戏内 → 圆点 → 设置 → **复制自检**，得到类似：

```
modLoader: yes
jquery: yes
passage: Bedroom
passagesNode: found
textLength: 812
choices: 4
connected: yes
vocab: 3
```

各项含义：

| 字段 | 不对时说明 |
|---|---|
| `modLoader` | 模组没被 ModLoader 加载 |
| `jquery` | 页面没有 jQuery，passage 钩子会退回 MutationObserver |
| `passage` | `(none)` = 读不到 `State.passage`，需要改选择器 |
| `passagesNode` | `missing` = 正文容器不是 `#passages` |
| `textLength` | 0 = 正文取不到（可能被 DoL 的自定义容器包住） |
| `choices` | 0 = 选项选择器不匹配（`a.link-internal`） |
| `connected` | 一直 no = World 没起或端口不对 |
