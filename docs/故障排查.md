# 故障排查

> 先做三件事，再做下面的对照表：
> 1. 仓库里跑 `node scripts/fw-check.mjs`（应三项 PASS）；
> 2. 游戏里 F12 看有没有 `[CooBridge] 已加载`；
> 3. 圆点 → 设置 → **复制自检**，留好那段文本。

---

## 一、装不上 / 看不到

| 现象 | 先看 | 常见原因与处理 |
|---|---|---|
| 手动安装选目录后报错 | Coopanion 的 `data/logs/core.log` 末尾 | `cortico.api` 不符（本包要求 world api 6）；`ws` 依赖没装上（网络/registry）；目录里没有 `package.json` |
| 装完侧栏没有「DoL 陪读」 | World 总览是否启用；`data/logs` | 装完必须**重启进程**才加载；`enabled` 默认 false，需要手动启用 |
| 面板打不开/白屏 | F12 控制台 | `dist/webui.js` 没随包安装（本地 link 安装不会丢；从 tarball 装时 `files` 已包含） |
| 面板里没有配置项 | 面板/设置页 | `worlds.dol.*` 配置组需要在 World 页展开；值写进部署的 `config.json` |

## 二、游戏里没有圆点

先分三种：

1. **控制台没有 `[CooBridge]`**：模组没加载。检查 Mod 管理器里 CooBridge 是否启用、`boot.json` 是否在 zip 根目录、zip 是否用构建脚本产出。
2. **有 `[CooBridge] 已加载` 但报错**：把报错原文发我。常见是 `ReferenceError`（构建产物执行顺序）——用最新构建。
3. **出现「CooBridge 已停用」全屏提示**：检测到汉化包或中文语言。这是预期行为，移除 `ModI18N` 或换英文原版。

## 三、圆点红/灰，连不上

自检里 `connected: no` 时：

| 检查 | 说明 |
|---|---|
| Coopanion 是否在运行、DoL World 是否启用 | World 没启用就没有本地服务 |
| World 面板端口 | 默认 17321；被占时顺延，面板会显示实际端口 |
| 防火墙 | 首次监听可能被拦；允许 Coopanion 访问专用网络 |
| 是否用了在线版 | GitHub Pages 是 https，浏览器禁止连 `ws://127.0.0.1`；请用本地 html |
| 控制台是否有 `连不上`/`WebSocket` 错误 | 模组会依次尝试 17321–17330，约 10 秒一轮 |

## 四、点词没反应 / 卡片不对

自检字段对照：

| 字段 | 异常值 | 含义 |
|---|---|---|
| `passagesNode` | `missing` | 正文容器不是 `#passages`，游戏版本可能改过布局 |
| `textLength` | `0` | 取不到正文，通常是容器选择器或渲染时序问题 |
| `choices` | `0` | 选项选择器不匹配（`a.link-internal` / `data-passage`） |
| `passage` | `(none)` | 读不到 `State.passage` |

卡片内容问题：

- **「无可靠词根」**：词根表没把握，按设计不硬编。可点「问 Coo 这个词」。
- **释义是「AI 推测」**：本地词典没收录，Coo 补的；有缓存，同一词不会重复请求。
- **同根词为空**：该词根条目没配示例，属正常。

## 五、问句一直「正在想」

1. 等 20 秒——超时后卡片会变「没等到 Coo 的回答」并给「重试」。
2. 若 20 秒后仍不变：说明 World 没收到请求或没回。看 World 面板「当前场景」是否在变、Coo 是否在说话。
3. Coo 侧问题：没接模型、被暂停、正忙于别的对话。面板连接正常但 Coo 无响应时，先直接跟 Coo 说句话测试。
4. 重试仍失败：把自检 + 那段时间的 `[CooBridge]` 日志发我。

## 六、Coo 不评论 / 太吵

- 模式在 Coopanion 的 DoL 陪读设置里：`主动` / `触发` / `被动`。
- 触发模式每场景最多一句，且受「每日评论上限」限制（默认不限，0 = 不限）。
- 被动模式不主动说话，只有你点句子/单词才回。
- Coo 是否真的开口还取决于它的人格与当前对话——World 只负责把事实交给它。

## 七、生词本与导出

- 生词存在游戏本地的 localStorage（`cb.vocab.v1`）。清浏览器站点数据会丢，先导出。
- 重启后生词消失：检查是否用了无痕窗口，或换了浏览器/文件路径（localStorage 按来源隔离，`file://` 下不同路径可能共享也可能不共享）。
- 导出 CSV 用 Excel 打开乱码：文件带 BOM，正常应无乱码；若仍乱码，用「数据 → 从文本导入」并选 UTF-8。
- World 面板的生词镜像是**只读副本**，以游戏内为准；镜像数量对不上时，点一下面板「刷新」。

## 八、汉化拦截的边界

判定顺序（任一命中即停用）：

1. mod 名是真正的汉化包：`modi18n` / `汉化` / `中文补丁` / `中文本地化`；
2. `mainLanguage` 不是 `en`；
3. **当前正文的汉字占比 ≥ 8%**（英文里偶尔出现人名汉字不触发）；
4. 页面 `lang` 不是 `en`。

所以：

- `I18nTweeReplacer` 这类通用翻译**插件**单独存在**不会**被拦；只有正文真的变中文、或装了 `ModI18N` 才会。
- 只装图片包（`GameOriginalImagePack`）不会触发。
- 停用提示是**顶部横幅，可关闭**，不会挡住 Mod 管理器；任何时候都能按 **Alt+M** 打开 Mod 管理器。
- 误拦：如果英文正文里汉字比例异常高（例如整段中文注释），会被判为汉化。改 `env.ts` 的 `ratio` 即可。

## 九、提交问题时请附上

1. `node scripts/fw-check.mjs` 的输出；
2. 游戏内「复制自检」的全文（含日志）；
3. Coopanion 版本、游戏版本（自检里的 `passage` 旁边能看到版本提示）；
4. 复现步骤：点了什么、期望什么、实际什么。
