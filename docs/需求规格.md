# DoL 陪读 · 需求规格

- 版本：v0.1（草案）
- 日期：2026-10-31
- 状态：需求已与项目所有者逐条确认，作为编码基线
- 关联：[技术方案](技术方案.md)

---

## 1. 目标

让使用者在 Coopanion 的 Coo 陪伴下玩 **Degrees of Lewdity 英文原版**，游戏内提供一层可开关的英语精读工具，形成
「读英文 → 点词 → 点句问 Coo → 记入生词本 → 间隔复习」的闭环。

成功标准（v0.1 验收时逐条判断）：

1. 玩家能连续玩 1 小时，模组不打断游戏、不报错、不丢存档。
2. 点任意单词 1 秒内出释义；本地没收录的词，点一下能让 Coo 补上并标注「AI 推测」。
3. 点任意句子，Coo 在 20 秒内给出中文翻译 + 一到两条讲解；同一句第二次点不再重复请求。
4. 生词本里的词能在第二天按间隔重新出现，且能导出。

---

## 2. 名词

| 词 | 含义 |
|---|---|
| Coo | Coopanion 的桌宠人格，本项目的陪玩与讲解者 |
| World | Cortico 扩展类型之一，把外部世界的事件交给 Coo、把可执行操作暴露成工具 |
| Mod | DoL 的 ModLoader 模组，运行在游戏页面内 |
| Passage | SugarCube 的一个场景单位，换场景即换 passage |
| 触发模式 | Coo 只在换场景/做选择这类事件点说一句，不主动出题 |
| 词根 | 前缀 / 词根 / 后缀的构词拆解，用于记忆，不等同于严格词源 |

---

## 3. 范围

### 3.1 做

- 英文原版 DoL（ModLoader 构建）＋ Coopanion 桌面版。
- 游戏内：单词卡（释义、词根、同根词）、整句问 Coo、生词本、间隔复习、导出、设置面板。
- World 侧：连接管理、场景同步、Coo 的三档模式、讲解工具、生词镜像、统计面板。

### 3.2 不做

- 不做中英双语对照（明确不兼容汉化包）。
- 不修改存档、不自动点选项、不自动存档、不替代汉化。
- 不支持 GitHub Pages 在线版、安卓 APK、macOS/Linux（代码不写死，但不承诺）。
- 不内置、不转载游戏正文或汉化译文。
- 不做词根家族复习（v0.1 只做卡片拆解，数据结构预留）。

## 4. 功能需求

优先级：P0 = v0.1 必须；P1 = v0.1 尽量；P2 = 后续。

### FR-01 连接与状态（P0）

模组启动后连接本机 World 的 WebSocket；断线自动重连（1s/2s/4s…上限 30s）；游戏内面板显示「已连接 / 未连接 / Coo 未响应」。

验收：
- 先开游戏后开 Coopanion，30 秒内自动连上，无需刷新页面。
- 关掉 Coopanion，游戏内 5 秒内显示「未连接」，游戏本身不受影响。

### FR-02 场景同步（P0）

每次 passage 切换，把 passage 名、正文（截断至 4000 字符）、选项列表、地点/天数/时间发送给 World。

验收：
- 换场景后 1 秒内 World 收到；同一 passage 重渲染不重复发送。
- 选项文本与游戏内可见链接一致（顺序、文字）。

### FR-03 Coo 短评（P0）

三档模式，默认「触发」：

| 模式 | 行为 |
|---|---|
| 主动 | 会主动评论剧情、在场景边界出题、提醒复习 |
| 触发 | 只在换场景、做选择时说一句；不主动出题 |
| 被动 | 只有玩家点句子/单词/面板时才说话 |

验收：
- 触发模式下连续 10 个场景，Coo 发言不超过 10 次，且不重复同一句。
- 切到被动后，不再收到任何主动评论。

### FR-04 点词查义（P0）

点击游戏正文里的任意英文单词，弹出单词卡：单词、音标、词性、中文释义、词根拆解、同根词、加入生词本按钮。

- 词形还原：`running` → `run`，`studies` → `study`；还原失败时按原词查。
- 本地词典未收录：卡片显示「未收录」＋「问 Coo」按钮，点击后由 Coo 补全，标注「AI 推测」并缓存。
- 卡片不遮挡被点的词；点击卡片外关闭。

验收：
- 常用词（top 3000）命中率 ≥ 95%。
- 查词不发起网络请求（本地词典）；Coo 补全除外。

### FR-05 词根拆解（P0）

单词卡固定包含词根块，格式：`in-（前缀·不） + cred（词根·相信） + -ible（后缀·可…的）`，并给 2–4 个同根词。

- 来源徽标：「本地」或「AI 推测」。
- 虚词、短词、借词优先判定「无可靠词根」，**禁止硬编**。
- 玩家可点「这条不对」，该条标记失效、不再复用；可重新问 Coo。

验收：
- 抽查 30 个词，拆解不与公认构词矛盾；不确定的词必须显示「无可靠词根」而不是编造。

### FR-06 点句问 Coo（P0）

点击/选中一句英文，弹出「问 Coo」卡：中文翻译 + 1–3 条讲解（语法点、搭配、语气），可折叠。

- 请求带句子哈希；命中缓存直接显示，不重复请求。
- 等待时显示「Coo 正在想…」，20 秒超时显示「没来得及回答」＋「重试」。
- Coo 未连接时按钮禁用并说明原因。

验收：
- 同一句第二次点击，0 网络请求、即时显示。
- 超时与失败不会让游戏卡顿。

### FR-07 生词本（P0）

- 加入：单词卡按钮；入项含单词、原形、所在句、passage、时间、词根（若有）。
- 列表：按时间倒序，可搜索、可删除、可标记「已掌握」。
- 存储：本地（localStorage），World 侧只读镜像。

验收：
- 关掉游戏再开，生词仍在。
- 同一单词重复加入不产生重复项，但刷新「最近出现」时间。

### FR-08 间隔复习（P0）

简易间隔：1 / 2 / 4 / 7 / 15 / 30 天。答对升一级，答错回一级。

- 复习形式：先给英文词，玩家自评「认识 / 模糊 / 不认识」；可展开看释义。
- 面板显示今日到期数量；到期待复习词可在游戏内卡片复习。

验收：
- 到期计算正确（跨天、跨时区按本地时间）。
- 复习记录可导出、可恢复。

### FR-09 导出（P0）

导出 JSON（完整备份）与 CSV（Anki 可导入：单词、释义、例句、词根）。

验收：
- 导出的 CSV 用 Excel 打开无乱码、列不串。

### FR-10 World 面板（P0）

Coopanion 的 World 页提供：连接状态、当前模式、发送范围、今日统计（查词数、问句数、复习数）、生词总数、导出、清空缓存。

验收：
- 不打开游戏时面板可正常打开，显示「等待游戏连接」。

### FR-11 汉化包检测与自禁用（P0）

检测到 `ModI18N` 或游戏语言为中文时：

- 显示不可忽略的错误提示，说明「本模组只支持英文原版，请移除汉化包」；
- **完全停用**：不连接 World、不注入任何学习 UI、不读写生词本。

验收：
- 装上汉化包启动，游戏可正常玩，模组不产生任何网络连接与控制台报错循环。

### FR-12 版本检测（P1）

读取游戏版本，与支持版本（`0.5.12.13`）比对；不匹配时在面板与控制台警告，但**不阻断**。

### FR-13 设置（P0）

游戏内设置页：模式、发送范围、词典开关、Coo 请求开关、字号、快捷键、清空缓存。
World 侧配置：端口、默认模式、每日评论上限、场景文本上限。

### FR-14 错误与日志（P1）

所有网络/解析错误写进游戏内「诊断」页（最近 50 条），可一键复制；World 侧写 `log`。

## 5. 发送范围

| 模式 | 发给 Coo 的内容 |
|---|---|
| 主动 | 整段场景正文 + 选项 + 地点/天数 |
| 触发 | 整段场景正文 + 选项 + 地点/天数 |
| 被动 | 仅玩家点选的句子/单词 |

成人内容照常处理，但 Coo 的讲解必须中性：不生成额外性描写，不评判，不回避术语。

---

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 注入后页面滚动/点击无可感延迟；单词卡打开 < 100ms；常驻内存增量 < 30MB |
| 稳定 | 任何异常都不得阻断游戏；所有 DOM 操作 try/catch，失败降级为「不可用」 |
| 隐私 | 默认只发当前场景；生词本与翻译缓存只存本地；不写任何远程服务器 |
| 可维护 | 协议版本化；两端共享 `packages/protocol`；纯逻辑（切句、还原、间隔）有单测 |
| 可发布 | 代码 MIT；包内不含游戏素材；词典与词根数据许可证单独核对（见 §8） |
| 兼容 | DoL `0.5.12.13` / ModLoader `2.101.1` / Coopanion `0.2.16`（world api 6） |

---

## 7. 内容边界

- Coo 的讲解：中性、教学化；遇到露骨内容不额外展开描写，只解释语言现象。
- 防剧透：Coo 不得根据 passage 名或后续内容预告剧情。
- 不代替玩家做选择；不评价玩家的选择。

---

## 8. 待定 / 开放问题

1. **词典数据源**：ECDICT 数据许可需核实；在核实前，构建脚本只在本地生成 `data/dict.json`，不进版本库、不随包分发。
2. **词根表**：v0.1 自建（目标 300–500 条），只收录把握大的；后续可换授权数据。
3. **Coo 响应延迟**：取决于 Coo 当前是否在说话；若实测经常 > 10 秒，需要在技术方案里加「快速通道」。
4. **复习提醒**：v0.1 只在游戏内提醒；游戏外提醒（World 定时事件）放 v0.2。
